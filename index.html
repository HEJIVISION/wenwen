? 填行业 + 产品 → 点本地生成 → 挑一条写文案或脚本 怎么用
  1. 填「行业」（必填），例：草莓电商、烧烤店、教培
  2. 填「具体产品」（强烈建议填），例：草莓、羊肉串。行业和产品分开填，标题才通顺
  3. 选「生意类型」——这个很关键：实物商品能拍"卖相最差"，服务行业不能，选了它会自动过滤
  4. 人群、地域选填——地域只对同城生意有用
  5. 点「本地生成」免费秒出；点「AI 增强」更具体，需要 Key
  6. 结果按分数从高到低排（满分 25），19 分以上优先拍，14 分以下一般别拍
  7. 看中哪条，点「写文案 →」或「写脚本 →」，选题和行业会自动带过去

? 粘 30 条同行标题 → 统计高频词和句式 → 重组选题 怎么用
  1. 打开抖音，搜你的行业关键词（例：草莓怎么挑）
  2. 找点赞高的视频，把标题一行一条复制下来，30 条以上最准
  3. 粘进框里，点「统计高频词和句式」
  4. 看同行反复在用哪些词、哪些句式最多（疑问开头／数字招法／避坑警示…）
  5. 点「用这些词重组 15 条选题」，套他们的句式，换成你的产品

手动粘贴 · 唯一的爆款研究入口

去抖音搜同赛道高赞，把标题一行一条粘进来。30 条以上统计才靠谱。
为什么只能手动：抖音有登录墙和反爬，任何自动抓取都拿不到它的数据，抓到的是网页文章不是视频标题。

? 选档位 → 填补充信息 → 生成 → 一键复制 怎么用
  1. 从选题页点「写文案 →」会自动带过来，也可以手填选题
  2. 选档位：短（配 15–30 秒）／标准（45–60 秒）／长（1 分钟以上）
  3. 填「补充信息」——真实数字、卖点、产地，越多越准
  4. 点「生成文案」，出：首句钩子／正文／行动指令／封面大字／置顶评论
  5. 点「复制全文」直接粘到抖音发布框
还没写文案填好选题，点「生成文案」
? 选档位 → 生成 → 出分镜表 怎么用
  1. 从选题页点「写脚本 →」会自动带过来
  2. 选档位，决定镜头数和字数：短1–3 镜／标准4–6 镜／长8–15 镜
  3. 「想强调的点」可以填一句，比如：3 斤净重更实在
  4. 点「生成脚本」，出分镜表：时间／画面／台词
  5. 点「复制口播」，只复制要念的台词，方便打印或贴提词器
还没写脚本填好选题，点「生成脚本」
? 粘别人爆款的口播 → 拆解 → 出对标选题 怎么用
  1. 找一个你想对标的爆款视频
  2. 把口播／字幕／标题复制下来，粘进大框里（粘得越全拆得越准）
  3. 填你的行业和身份（例：草莓／98 年返乡、3 个棚）
  4. 点「拆解」，出：钩子类型／中间痛点／结构骨架／结尾引导／情绪价值／用户画像
  5. 最后看「哪些能抄、哪些抄不了」，以及给你的 3 条对标选题
还没拆解把别人的爆款口播粘进来
? 录一个品 → 看值不值得带 → 一键出带货脚本 怎么用
  1. 抖音 → 商品 → 精选联盟，找你想带的品
  2. 把价格、佣金率、预估销量、退货率抄下来，填进下面
  3. 系统自动算：一单赚几块、值不值得带、有什么坑
  4. 录 3 个以上，会按性价比排序，告诉你先带哪个
  5. 看中一个，点「出带货内容」→ 生成选题和脚本
